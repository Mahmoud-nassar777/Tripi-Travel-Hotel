# Tripi – Travel & Hotel Landing Page

A modern and responsive travel landing page designed to showcase popular destinations, hotel recommendations, traveler reviews, and travel-related content. Built with Next.js, TypeScript, and Tailwind CSS.

## Overview

Tripi is a travel-inspired landing page UI that brings together destination discovery, hotel listings, customer testimonials, and travel news in a clean and responsive layout.

The project focuses on modern UI design, reusable React components, responsive layouts, and interactive visual elements.

## Features

- Responsive navigation with mobile menu
- Hero section with background video
- Travel search UI with location and date inputs
- Popular destinations carousel
- Recommended hotel cards
- Why Choose Us section
- Testimonials carousel
- Travel news section
- Newsletter subscription UI
- Scroll-to-top button
- Scroll animations
- Responsive layout across screen sizes

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- AOS (Animate On Scroll)
- Swiper
- React Multi Carousel
- React Icons

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/tripi-travel-landing-page.git
```

Navigate to the project directory:

```bash
cd tripi-travel-landing-page
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
